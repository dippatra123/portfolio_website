#  Developer Portfolio with AI Agent

A modern, responsive developer portfolio website designed to showcase my skills, projects, experience, and professional profile.

The portfolio also includes an **AI-powered agent** that allows visitors to interact with my portfolio through natural-language conversations and get information about my projects, skills, experience, and background.

## Features

  AI-powered portfolio agent
  Natural-language interaction with visitors
  About Me section
  Skills and technologies
  Project showcase
  Downloadable CV
  Contact section
  Interactive location map
  Fully responsive design
  Modern and interactive UI
  Fast and smooth user experience

##  AI Agent

The AI agent is integrated directly into the portfolio to make it interactive.

Visitors can ask questions such as:

- "What projects has he built?"
- "What technologies does he know?"
- "Tell me about his experience."
- "What is his strongest skill?"
- "How can I contact him?"
- "Can I download his CV?"

The agent responds based on the information provided about my professional profile.
